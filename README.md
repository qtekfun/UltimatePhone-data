# UltimatePhone-data

Data packs for [UltimatePhone](https://github.com/qtekfun/UltimatePhone): business names by phone number
(derived from OpenStreetMap) and prefix rules. They are published as releases of this repository.

- Code: GPL-3.0-or-later (`LICENSE`).
- Business data: ODbL 1.0, © OpenStreetMap contributors (`LICENSES/`).
